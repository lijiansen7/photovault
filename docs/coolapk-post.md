# 📦 PhotoVault —— 把手机照片原样备份到自家 NAS，EXIF 一张不丢

> 自己写的 Android 照片备份方案：**手机 App + 跑在 NAS 上的服务端**，
> 照片只存在你自己的硬盘里，不经过任何公有云。

---

## 🤔 为什么要自己写一个

- 云相册要么**收费**、要么**压缩画质**、要么照片躺在别人的服务器上
- NAS 自带方案（群晖 Moments / Synology Photos 之类）只认自家生态，换设备就尴尬
- 我想要的是很朴素的一件事：
  **原文件原样备份 → 随时还原回手机 → 拍摄时间、GPS、相机型号都还在**

---

## ✨ 核心特性

**① 原文件字节级备份，EXIF 完整保留**
不做任何转码压缩。还原回手机后，系统相册读到的还是**拍摄当天的日期**和**原来的定位**，不是"导入时间"。

**② 内容去重，不浪费空间**
按 SHA256 指纹去重。同一张照片在微信、相机、截图里各有一份？**只存一份**，也不会重复传。

**③ 还原回原目录（重点）**
哪备份的还原到哪：`DCIM/Camera`、`Pictures/WeiXin`…… 不是统统丢进一个文件夹里让你重新整理。

**④ 还原冲突三种策略**
- **跳过**（默认）：手机里已有的不动，幂等，重复点不会产生一堆副本
- 留两份 / 覆盖：按需选

**⑤ 增量备份 + 粗筛加速**
只传 NAS 上没有的。绝大多数照片**不用读文件内容**就能判定跳过，第二次备份几乎是秒过。

**⑥ 按文件夹浏览**
NAS 相册支持 `DCIM/Camera`、`Pictures/WeiXin` 这样按真实目录分类查看，滑动到底自动加载。

**⑦ 视频也有封面**
手机上传时顺手抽一张首帧，服务端不用装 ffmpeg。

**⑧ 删除先进回收站**
误删能恢复；回收站支持**勾选后只清空选中的**，不用一次全清。

**⑨ 多用户**
家里一人一个账号，各看各的；管理员可看全部。

**⑩ 网页管理端**
按日期分组、批量选择删除、完整性巡检（索引和磁盘对账）。

**⑪ 取消备份 + 真实进度条**
同步中随时「取消」，已经传上去的不受影响；进度显示 "已备份 x/y"。

**⑫ 上传大小不限制**
几个 G 的长视频照样传（想兜底可以自己设上限）。

## 🐳 部署（NAS 上）

```bash
cd photovault/server
# 编辑 docker-compose.yml：
#   1) INIT_ADMIN_PASSWORD 改成自己的强密码
#   2) volumes 改成照片存放目录（群晖 /volume1/photo、威联通 /share/Container/photo）
docker compose up -d
```

浏览器打开 `http://NAS的IP:8765` 就能看到网页管理端。
群晖/威联通/Linux 都行，只要有 Docker。

## 👍 适合谁

- 有 NAS（群晖/威联通/自建都行）
- 在意照片**在自己手里**，不想被云空间收费
- 换手机、重装系统后想**完整还原**相册，且时间/位置信息不能乱

## 🙅 不太适合

- 没有 NAS，只想开箱即用
- 需要多端实时协作共享相册
- 指望它替代完整的云端相册生态

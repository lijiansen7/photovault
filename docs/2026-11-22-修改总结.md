## 3. 服务端修改

### 3.1 网页控制台视觉

- 顶栏改为吸顶毛玻璃，标签栏改为圆角胶囊，新增「回收站」标签。
- 页面背景增加品牌色径向渐变；卡片/按钮/输入框/登录框统一圆角、阴影和渐变主色。
- 照片网格、文件夹筛选、加载更多在窄屏自适应；移动端标签栏自动换行。
- 登录页改为渐变卡片布局。
- HTML/JS 加 `no-store` 和构建版本参数，升级后不再长期缓存旧页面。

### 3.2 回收站与照片页

- 回收站从照片工具栏移到顶栏：照片 / 回收站 / 用户 / 维护 / 关于。
- 回收站支持批量选择、恢复所选、永久删除所选；新增 `/api/trash/restore`。
- 修复回收站缩略图/原图 404：媒体接口允许读取 `deleted=1` 的回收站照片。
- 照片页支持「全部 + 各文件夹」筛选；修复「未分类」筛不到 `rel_dir` 为空照片。
- 回收站按日期分组，永久删除前有确认弹窗。

### 3.3 关于页与教程

- 展示服务端版本、页面构建时间、服务地址、当前账号、健康状态。
- 新增四步教程：连接 NAS、选择相册、首次同步、删除同步。
- 新增手机端/网页端日常操作卡片和常见问题。
- 新增 HTTPS 证书卡片：换证书不用 SSH，飞牛文件管理覆盖 certs 后重启。
- 新增管理员「启用/关闭 HTTPS」开关；切换后写 `data/certs/https.enabled` 并自动重启。
- 页面域名使用「你的域名」占位，不再写死实际域名。

### 3.4 认证与缩略图

- `/api/auth/me` 为老网页会话补发 HttpOnly cookie，修复缩略图 401。
- 缩略图/原图 URL 不再带 token，登录后由 cookie 鉴权。
- 静态资源与首页加 no-cache/no-store，`console.js` 带构建版本参数。
- 回收站照片缩略图/原图可预览。

### 3.5 直连 HTTPS 与端口

没有使用 nginx/Caddy 反向代理。uvicorn 直接监听 8765 并加载 `creak.eu.org` 的 TrustAsia 证书；飞牛统一网关的 Unix Socket 由 socat 用 TLS 连回本机 8765。

| 项目 | 当前值 |
|---|---|
| 证书/私钥 | `/vol1/1000/PhotoVault/certs/creak.eu.org.crt / .key` |
| 证书有效期 | 2027-02-20（TrustAsia） |
| 容器主端口 | 8765（HTTPS） |
| 飞牛网关 | Unix Socket → socat TLS → 127.0.0.1:8765 |
| HTTPS 开关 | `/data/certs/https.enabled`（1 开 / 0 关） |
| 入口脚本 | `server/entrypoint.sh`；当前容器 `/srv/entrypoint.sh` |

> 关闭 HTTPS 后 8765 回到 HTTP，App 外网地址也要改成 `http://`。

### 3.6 设备 ID 管理

- 新增 `POST /api/device/rename`：把当前用户旧设备 ID 下的照片和 `photo_devices` 映射迁到新 ID。
- 新增 `GET /api/admin/devices`：管理员按用户列出设备 ID、存活照片、回收站数量、最近上传时间。
- 网页「用户」页新增设备 ID 表格，支持复制，用于卸载重装/自定义 ID 后找回旧 ID。
- 迁移接口做过 round-trip：`b25c45ad466d → testtmp → b25c45ad466d`，各迁移 2881 条。

## 4. Android App 修改

### 4.1 视觉与导航

- 底部导航改为悬浮圆角栏，选中态品牌色。
- 页面背景增加轻微品牌色渐变；首页增加「照片备份」标题。
- NAS 连接卡：渐变背景、圆形 WiFi 图标、状态圆点、延迟徽章、当前线路、服务端版本。
- 存储概况改为照片/视频/占用三块小卡片，保留本机、NAS、位置、最后备份明细。
- NAS 相册增加大标题、统计、文件夹筛选。
- 回收站增加大标题、总数、选择操作条；分页 120 张、缩略图 256px、关闭 crossfade。
- 设置页统一标题；回收站/自动备份/高级/关于分区更清楚。

### 4.2 内网/外网双地址

- 设置页由单地址改为「内网地址（优先）」+「外网地址（备用）」。
- `EndpointRouter`：优先内网；内网 `/api/health` 2 秒不通即切外网；60 秒内避免反复探测。
- 网络失败时自动用外网重试一次；登录、后台备份、静默重登、相册、回收站统一走该逻辑。
- 首页显示当前实际走的地址（内网/外网）和延迟。
- 当前配置：内网 `http://192.168.108.169:8767`；外网 `https://creak.eu.org:8765`。

### 4.3 一键还原进度与取消

- `RestoreWorker` 通过 `setProgress` 上报 done/total/text。
- 所有还原请求打 `photovault_restore` tag，NAS 相册页观察 WorkManager 状态。
- 还原中显示卡片：进度条、当前文件、完成数/总数、取消按钮。
- 取消调用 `cancelAllWorkByTag` 并取消通知；已写入相册的文件不撤回。
- 一键还原全部、选中还原、单张还原都会显示。

### 4.4 回收站恢复

- App 回收站新增「恢复」按钮，调用 `/api/trash/restore`。
- 恢复只把照片恢复到 NAS 相册，不会自动写回手机；需再去 NAS 相册点「还原选中」。
- 恢复后提示「已恢复 N 张到 NAS 相册」。

### 4.5 设备 ID

- 默认由 `Settings.Secure.ANDROID_ID` 的 SHA-256 前 6 字节派生，格式 `android-xxxxxxxxxxxx`。
- 同一手机、同一签名、同一用户下，卸载重装/清数据不变；恢复出厂/换签名包会变。
- 当前设备 ID：`android-b25c45ad466d`；NAS 已把旧 2881 条记录迁到该 ID。
- 关于卡片显示版本、构建时间、设备 ID、自动/自定义，并提供复制/修改。
- 修改设备 ID 会先调用 `/api/device/rename` 迁移 NAS 记录，再写本地；自定义后重装要填回同一 ID。

## 7. 已知问题与待办

### 7.1 外网 8765 仍不可达（最高优先级）

同一台手机、纯 5G 实测：5667 可连接，8765/8766/9443 全部超时。NAS 本机 8765 在监听，Docker DNAT 和 conntrack 均能看到外部连接；iKuai DMZ 绑定的是 wan2（专线），而 `creak.eu.org` 的 `59.36.251.110` 很可能属于另一条 WAN。

当前判断：DMZ 绑错 WAN，或该 WAN 只做了 5667 的端口映射。

- 在 iKuai 确认 `59.36.251.110` 属于哪个 WAN。
- 把 DMZ 外网地址改成该 WAN；或映射类型选「外网IP」并填 `59.36.251.110`，内网 `192.168.108.169`。
- 如仍不通，在该 WAN 增加 TCP `8765 → 192.168.108.169:8765` 的端口映射。
- 不要长期把 8767（局域网 HTTP）暴露到公网。

### 7.2 其他

- x86/arm64 离线 fpk 未打包（用户中途停止）；manifest 版本已改为 1.4.0，镜像标签仍为 1.3.0。
- 自定义设备 ID 后，卸载重装需手动填回同一 ID；自动 ID 无此负担。
- 证书 2027-02-20 到期；续期后需替换 `/vol1/1000/PhotoVault/certs` 并重启容器。
- 网页端「关于」不展示手机设备 ID；设备 ID 在 App「关于」和管理员「用户 → 设备 ID」表里。

## 9. 恢复与回滚要点

- **误删照片**：先不要清空 NAS 回收站；App 设置→回收站→恢复，再到 NAS 相册→还原选中。
- **数据库异常**：停止容器，用 `/data/index.db.bak-*` 恢复 `index.db`，再启动。
- **HTTPS 切换异常**：把 `/data/certs/https.enabled` 改回 `1` 或 `0`，重启容器；证书文件在 `/vol1/1000/PhotoVault/certs`。
- **入口脚本异常**：用 `/vol1/1000/PhotoVault/entrypoint.sh.bak` 覆盖 `/srv/entrypoint.sh` 后重启。
- **卸载 App 前**：先备份 `device_id` / preferences，或确认已改用稳定 Android ID。
